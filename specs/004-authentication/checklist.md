# Module 4 Checklist: Database Design and Authentication

## Verification & Sign-off Criteria (Weeks 7–8)

- [ ] **Criterion 4.1:** MongoDB collections designed and verified for users, menu items, and orders.
- [ ] **Criterion 4.2:** User registration endpoint accepts valid payloads and hashes passwords.
- [ ] **Criterion 4.3:** User login endpoint verifies credentials and issues valid JWT tokens.
- [ ] **Criterion 4.4:** Role-based access control tested and operational (`cashier`, `kitchen`, `manager`).
- [ ] **Criterion 4.5:** Backend validation catches missing or malformed fields, returning descriptive 400 errors.
- [ ] **Criterion 4.6:** Centralized error handling prevents unhandled exceptions from crashing the server.
