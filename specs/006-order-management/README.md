## 1. Module Overview & Proposal Objectives

This module implements the core cashier ordering system, supporting Dine-in, Takeaway, and Delivery workflows, real-time ticket building with item additions and removals, and order persistence and retrieval via REST APIs.

### Original Proposal Objectives:
- Create new restaurant orders.
- Support dine-in, takeaway, and delivery orders.
- Add or remove items before order confirmation.
- Store orders and retrieve order details through APIs.
