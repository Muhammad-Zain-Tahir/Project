# SmartDine - Restaurant Ordering & Management System

A modern restaurant ordering and management application.

## Project Details

- Developer: Muhammad Zain Tahir
- Project Type: Final Year CIT Project
- Technology: MERN Stack
- Methodology: Spec-Driven Development (SDD)
- Duration: 6 Months
- Status: Under Development

## Main Features

- Authentication and Role-Based Access
- Menu Management
- Order Management
- Billing and Invoice
- Kitchen Order Processing
- Table, Takeaway and Delivery Management
- Dashboard and Sales Reports

## Project Structure

- specs: Feature specifications, plans and tasks
- frontend: React application
- backend: Node.js and Express API
- docs: Project documentation
- tests: Testing resources
