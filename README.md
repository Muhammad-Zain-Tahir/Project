# 🍽️ SmartDine – Restaurant Management System

SmartDine is a MERN Stack-based Restaurant Management System developed as a Final Year CIT Project. It aims to simplify restaurant operations through digital order management, billing, and kitchen order processing.

## 🚀 Features
- Restaurant Order Management
- Digital Billing and Invoicing
- Menu Management
- Dine-In, Takeaway, and Delivery Orders
- Kitchen Order Processing
- Responsive and User-Friendly Interface

## 🛠️ Technologies Used
- MongoDB – Database
- Express.js – Backend Framework
- React.js – Frontend Library
- Node.js – Runtime Environment
